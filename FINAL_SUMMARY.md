## 🚀 DÉMARRAGE RAPIDE

### 1. Backend
```bash
cd backend
npm install
npx prisma generate
npx prisma migrate dev
npm run dev
# Backend lancé sur http://localhost:3000
```

### 2. Frontend Web
```bash
cd frontend
npm install
npm start
# Frontend lancé sur http://localhost:3001
```

### 3. Mobile App
```bash
cd mobile
npm install
npm start
# Scanner QR code avec Expo Go
# Ou: npm run android / npm run ios
```
