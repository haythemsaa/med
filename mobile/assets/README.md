# Assets

Ce dossier contient les ressources de l'application mobile.

## Images requises

### Icônes
- `icon.png` - Icône de l'app (1024x1024px)
- `adaptive-icon.png` - Icône adaptative Android (1024x1024px)
- `favicon.png` - Favicon web (48x48px)

### Splash Screen
- `splash.png` - Écran de démarrage (1284x2778px)
